# LG Remote

Controle remoto Android para LG webOS via Wi-Fi, sem anúncios.

## Build
Abra Actions > Build Android APK > Run workflow, ou faça push para main. Baixe o APK em Artifacts.

## Uso
Conecte celular e TV à mesma rede. Informe o IP da TV, toque Conectar e aceite o pareamento na TV. O app salva a chave de autenticação localmente.

## Limitações
Atalhos exigem aplicativos instalados na TV; entrada de texto depende do campo e da versão do webOS. Ligar TV desligada exige Wake-on-LAN e configuração adicional, não incluída nesta versão.
